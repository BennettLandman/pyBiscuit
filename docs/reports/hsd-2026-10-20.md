Status: B6.1, B6.3, B6.4, B6.5 (property-only), B6.6 done against the **provisional** oracle (macOS arm64,

## Findings for the owner

1. The shipped HSD has no landmark/location options (image `strings` = upstream wrapper). The brief's flag list over-counts.
2. "Levenberg-Marquardt" is gradient descent below icosahedron level 6 and a damped Gauss-Newton step above; BOBYQA is only used by the landmark
   path. The B6.5 BOBYQA item is therefore dead code for BISCUIT.
3. Likely BISCUIT call: pair-wise mode with the template as fixed subject 0 (hypothesis, port note). Needs B1.2 confirmation.
4. `--icomesh` with a radius-100 sphere breaks the initial guess upstream (mean map 0) unless `--resample` normalises it. Check how BISCUIT calls HSD.
5. `m_cost_lm` is uninitialised upstream (we use 0); `--icosahedron 0-2` has an uninitialised sample count.
